> *"Tap to bounce, groove to the beat, and navigate tricky obstacle corridors in this vibrant mobile arcade physics runner."*

**DrDance** is an energetic, rhythm-infused mobile physics game built in Unity and released for Android (`.apk`). Reimagining classic tap-to-fly mechanics with dance animations and groovy musical beats, players guide the dancing doctor through rhythmic obstacle gaps.

📱 **Android APK**: Download `DrDance.apk` directly from this repository.

---

## 🎵 Key Features

* **Rhythm Tap Impulse**: Tuned vertical impulse physics synchronized with upbeat musical cues.
* **Procedural Obstacle Spawning**: Dynamically generated obstacle gates with varying vertical clearance and speed scaling.
* **Score Tracking & Persistence**: Real-time score counter with local high-score saving via Unity `PlayerPrefs`.
* **Mobile-Optimized Build**: Lightweight APK footprint optimized for smooth 60 FPS performance across a wide range of Android hardware.

---

## 📱 How to Install on Android

1. Download **`DrDance.apk`** from the repository to your Android device.
2. Tap the file in your Downloads folder.
3. If prompted, allow "Install from unknown sources" in Android settings.
4. Launch DrDance and start grooving!
